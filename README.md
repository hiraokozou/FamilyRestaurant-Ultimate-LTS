# FamilyRestaurant-Ultimate-LTS

家庭用本格ファミレスごっこWebシステム

## 📌 概要

FamilyRestaurant-Ultimate-LTSは、家庭で本格的なファミリーレストラン体験を楽しむためのWebシステムです。

実際のファミレスにあるような、

- 注文システム
- 厨房管理
- ホール管理
- レジ
- レシート発行
- 店長管理

などを再現します。

さらに、

- ガチャ
- ミニゲーム
- オリジナル電子決済システム（Family Pay）
- AI店員

などの遊び要素も追加予定です。
