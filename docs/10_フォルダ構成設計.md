# 1. 目的

本設計書では、プロジェクト全体のフォルダ構成と役割を定義する。

機能ごとにフォルダを分けることで、保守性・拡張性・可読性を向上させる。

# 18. 設計方針

・役割ごとにフォルダを分離する

・共通処理は shared にまとめる

・Node.js と画面を分離する

・将来の機能追加に対応できる構成とする
