# FamilyRestaurant-Ultimate-LTS
# データベース設計書

---

# 1. 目的

本設計書では、本システムで使用するデータベース構成を定義する。

データはSQLiteで管理し、将来的にMySQL・PostgreSQLへ移行できる設計とする。

---

# 2. データベース構成

本システムでは以下のテーブルを使用する。

・categories
・products
・product_options
・tables
・orders
・order_items
・staff
・receipts
・settings
・logs

---

# 3. categories

カテゴリ情報

|項目|型|説明|
|---|---|---|
|id|INTEGER|カテゴリID|
|name|TEXT|カテゴリ名|
|sort_order|INTEGER|表示順|
|created_at|TEXT|作成日|
|updated_at|TEXT|更新日|

---

# 4. products

商品情報

|項目|型|説明|
|---|---|---|
|id|INTEGER|商品ID|
|category_id|INTEGER|カテゴリID|
|product_code|TEXT|商品コード|
|name|TEXT|商品名|
|description|TEXT|説明|
|price|INTEGER|価格|
|cook_time|INTEGER|調理時間(分)|
|image|TEXT|画像|
|status|TEXT|販売状態|
|sort_order|INTEGER|表示順|
|created_at|TEXT|作成日|
|updated_at|TEXT|更新日|

---

# 5. product_options

商品のオプション

|項目|型|説明|
|---|---|---|

|sort_order|INTEGER|表示順|
