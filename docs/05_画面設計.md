# FamilyRestaurant-Ultimate-LTS
# 画面設計書

---

# 1. 目的

本設計書では、本システムで使用する全画面の役割と画面遷移を定義する。

各画面はスマートフォン・タブレット・PCで利用できるレスポンシブデザインを採用する。

---

# 2. システム全体

```
トップ画面
│
├── 客画面
│
├── スタッフ画面
│
├── 厨房画面
│
└── 店長画面
```

# 10. デザイン方針

客画面

・すかいらーくグループ風の操作感
・大きなボタン
・写真中心
・子どもでも操作しやすい

スタッフ画面

・業務優先
・通知を目立たせる
・座席状況を一目で確認できる

厨房画面

・大きな文字
・シンプル表示
・調理状況がすぐ分かる

店長画面

・管理画面らしい表形式
・編集しやすいUI
・星街すいせい風のカラーイメージ（※権利物は使用せず、青系・近未来感をイメージ）
