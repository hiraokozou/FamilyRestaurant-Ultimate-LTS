# FamilyRestaurant-Ultimate-LTS
# バージョン管理・アップデート設計書

---

# 1. 目的

本設計書では、システムのバージョン管理およびアップデート方法を定義する。

LTS版として長期間安定して利用できる運用を目標とする。

---

# 2. バージョン形式

Semantic Versioning（セマンティックバージョニング）を採用する。

形式

vMAJOR.MINOR.PATCH

例

v1.0.0

v1.1.0

v1.1.5

v2.0.0

---

# 3. バージョンアップルール

MAJOR

互換性がない変更

例

・システム全体の変更

・DB構造変更

・API変更

---

MINOR

新機能追加

例

・ガチャ追加

・新画面追加

・Family Pay連携

---

PATCH

不具合修正

例

・表示崩れ修正

・誤字修正

・軽微な改善

---

# 4. リリース種別

Development

開発版

Beta

試験版

Release Candidate（RC）

公開候補版

LTS

長期サポート版
