# FamilyRestaurant-Ultimate-LTS
# 画面デザイン設計書

---

# 1. 目的

本設計書では、システム全体のデザインルールを定義する。

すべての画面で統一感のあるUIを採用し、
子どもから大人まで使いやすいデザインを目指す。

・リアル

# 15. Ultimate-LTS目標

家庭で遊びやすい親しみやすさを両立したUIを実現する。
