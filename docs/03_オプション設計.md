# FamilyRestaurant-Ultimate-LTS
# オプション設計書

---

# 1. 目的

本設計書では、商品のカスタマイズ機能（オプション）の仕様を定義する。

オプションは商品ごとに自由に設定できるものとし、
店長画面（メニューエディター）から追加・編集・削除できる。

---

# 2. 基本方針

・商品ごとに複数のオプションを設定できる

・オプションは自由に追加できる

・価格変更に対応する

・厨房へ正確な内容を送信する

---

# 3. オプション種類

例

ライス

パン

ソース

サイズ

トッピング

ドリンク

焼き加減

その他

店長画面から自由に追加できる。

---

# 4. オプショングループ

一つの商品に複数のグループを設定できる。

例

トッピング

ドリンク

# 6. 追加料金

各オプションには追加料金を設定できる。

例

ライス大盛

+100円

チーズ追加

+150円

エビ追加

+250円

価格変更なしの場合は0円とする。

---

# 7. 必須・任意

各オプショングループには

必須

または

任意

を設定できる。

例

ライス

必須

トッピング

任意

---
