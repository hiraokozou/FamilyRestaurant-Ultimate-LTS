# FamilyRestaurant-Ultimate-LTS
# バックアップ・復元設計書

---

# 1. 目的

本設計書では、データのバックアップおよび復元機能を定義する。

システム障害や誤操作が発生した場合でも、安全にデータを復旧できることを目的とする。

---

# 2. バックアップ対象

以下のデータをバックアップ対象とする。

・データベース（SQLite）
・メニュー情報
・カテゴリ
・オプション設定
・店舗設定
・レシート履歴
・営業履歴
・ログ
・画像（商品画像・ロゴ）
・テーマ設定

---

# 3. バックアップ方法

対応する方式

・手動バックアップ
・営業終了時の自動バックアップ
・定期バックアップ（毎日・毎週など）
・バックアップ前に確認ダイアログを表示（設定で省略可）

---

# 4. 保存先

初期設定

```
backups/
```

例

```
backups/

2026-08-05_220000/

database.db

menu.json

settings.json

receipts.json

logs.json

images/

backup-info.json
```

---

# 5. バックアップ情報

保存内容

・バックアップID
・作成日時
・営業ID
・作成者
・アプリバージョン
・バックアップサイズ
・メモ（任意）

---

# 6. 復元

店長のみ実行可能。

復元前に

「現在のデータを上書きします」

と確認を表示する。

復元対象

・全データ
・メニューのみ
・設定のみ
・画像のみ
・営業履歴のみ

---

# 7. 世代管理

保持数を設定可能。

例

・最新10件
・最新30件
・無制限

古いバックアップは手動または自動で削除できる。

---

# 8. エクスポート

外部へ保存可能。

対応形式

・ZIP
・JSON
・SQLiteファイル

---

# 9. インポート

他の端末からバックアップを読み込める。

利用例

・新しいPCへ移行
・別環境でテスト
・データ共有（家庭内）

---

# 10. 自動バックアップ

営業終了時

↓

バックアップ開始

↓

完了通知

↓

ログへ記録

---

# 11. エラー対応

・容量不足
・保存失敗
・破損ファイル
・復元失敗

エラー内容をログへ保存する。

---

# 12. セキュリティ

バックアップの実行・復元は店長権限のみ。

必要に応じてPINコードの再入力を求める。
