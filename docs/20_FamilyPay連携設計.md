# FamilyRestaurant-Ultimate-LTS
# Family Pay連携設計書

---

# 1. 目的

本設計書では、FamilyRestaurant-Ultimate-LTSと
Family Payシステムとの連携仕様を定義する。

Family Pay本体は独立したプロジェクトとして開発し、
本システムでは決済連携のみを行う。

---

# 2. システム構成

┌────────────────────┐
│ Family Restaurant │
└────────┬───────────┘
         │
         │ API
         ▼
┌────────────────────┐
│    Family Pay      │
└────────┬───────────┘
         │
         ▼
   Family Pay Database

Restaurant側は残高や決済結果を利用する。

# 13. 開発方針

Family Restaurant

↓

Family Pay

という一方向の依存関係とする。

Family PayはRestaurantに依存しない。

---

# 14. Ultimate-LTS方針

Family Payは独立した決済サービスとして開発し、

Restaurant側はAPIを利用するクライアントとして実装する。

これにより、将来的に他のアプリやゲームともFamily Payを連携できる設計とする。
