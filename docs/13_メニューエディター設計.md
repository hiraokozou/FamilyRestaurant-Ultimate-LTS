# FamilyRestaurant-Ultimate-LTS
# メニューエディター設計書

---

# 1. 目的

メニューエディターは、店長がブラウザから商品の追加・編集・削除・表示設定を行える管理システムである。

HTMLやデータベースを直接編集することなく、GUIだけで店舗メニューを管理できることを目標とする。

# 14. Ultimate-LTS方針

メニューエディターだけで店舗運営に必要な設定を完結できることを目標とする。

将来的な機能追加を考慮し、柔軟で拡張性の高い設計とする。
