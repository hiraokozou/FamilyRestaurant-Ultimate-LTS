# 13. 開発方針

すべての画面は一つのNode.jsサーバーで管理する。

役割ごとに画面を分けることで保守性・拡張性を高める。

SQLiteはデータ保存専用とし、通信処理はNode.jsが担当する。

---

# 14. 完成イメージ

家庭内の複数端末が同時に接続し、

客・厨房・スタッフ・店長がリアルタイムで連携できるシステムを実現する。
